# Coach Dashboard Module

## Responsibility & Boundaries
The **Coach Dashboard** provides individual specialist coaches with tools to deliver 1-on-1 coaching to assigned clients.

### Key Capabilities
- **Assigned Client Roster**: Inspect assigned clients, check training history, and update progress notes.
- **Workout Program Building**: Create tailored workout routines and submit them to Head Coach for approval.
- **Nutrition Plan Building**: Design macro nutrition blueprints for assigned clients.
- **Task Desk**: Manage assigned coaching tasks, consultation requests, and client feedback.
