# Admin Dashboard Module

## Responsibility & Boundaries
The **Admin Dashboard** provides complete operational authority over the BxStrength platform.

### Key Capabilities
- **User & Role Management**: View, create, update, activate/deactivate accounts for Head Coaches, Coaches, Customer Support, and Clients. Admin password reset and 360 Client Profile Inspection.
- **Coach & Head Coach Delegation**: Assign clients to Head Coaches or Coaches with live status sync.
- **Financial Subscriptions & Billing**: Manage active billing tiers, custom pricing, and recurring subscription statuses.
- **Platform Audit & Security**: Track system audit logs, configure RBAC feature toggles, and manage active platform settings.
- **Announcements**: Publish broadcast messages across the client portal.
