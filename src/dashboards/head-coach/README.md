# Head Coach Dashboard Module

## Responsibility & Boundaries
The **Head Coach Dashboard** provides athletic supervision, central assignment control, and program QA.

### Key Capabilities
- **Central Assignment Engine**: Delegate clients, workout programs, diet plans, and strategy sessions to specialist coaches.
- **Workout & Nutrition QA**: Review and approve workout protocols and macro diet blueprints prepared by coaches before publishing to clients.
- **Client & Coach Oversight**: Inspect active client progress and supervise coach performance.
- **Enquiry Allocation**: Review incoming client strategy session requests and allocate to available coaches.
